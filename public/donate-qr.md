# Происхождение `donate-qr.svg`

QR-код ведёт на страницу приёма чаевых:

    https://pay.cloudtips.ru/p/86c3292c

Сгенерирован разово, постоянной зависимости в проекте нет:

```bash
npx -y qrcode -o public/donate-qr.svg -t svg -m 1 -e M \
  -d "#0a0e18ff" -l "#00000000" "https://pay.cloudtips.ru/p/86c3292c"
```

Генерация детерминирована: повторный запуск команды даёт побайтно тот же файл.
Это и есть способ проверки — чтобы убедиться, куда ведёт код, не нужно его
сканировать, достаточно перегенерировать и сравнить.

Модули тёмно-синие, фон прозрачный: светлую подложку под код даёт CSS
(`.support-qr img`). Без светлой подложки код не читается сканером — он
распознаётся по контрасту, а тёмное на тёмном контраста не даёт.
